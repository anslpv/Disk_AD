# Disk_AD

PowerShell-скрипт `Get-DomainDiskInventory.ps1` собирает данные о жестких дисках
со всех компьютеров домена Active Directory (модель, серийный номер, электронный
идентификатор и др.) и формирует отчеты в CSV и HTML.

## Требования

- PowerShell 5.1 или новее.
- Модуль `ActiveDirectory` (RSAT), если список компьютеров берется из AD.
- Права локального администратора на опрашиваемых компьютерах
  (текущая учетная запись или `-Credential`).
- На целевых компьютерах: WinRM (TCP 5985) или DCOM/RPC (TCP 135 + динамические порты)
  и ответ на ICMP (ping).

## Запуск

```powershell
# Все включенные компьютеры домена
.\Get-DomainDiskInventory.ps1

# Только одно подразделение, без USB-дисков
.\Get-DomainDiskInventory.ps1 -SearchBase "OU=Workstations,DC=corp,DC=local" -ExcludeUsb

# Только серверы
.\Get-DomainDiskInventory.ps1 -OperatingSystem "*Server*"

# Конкретные компьютеры под другой учетной записью
.\Get-DomainDiskInventory.ps1 -ComputerName PC01,PC02 -Credential (Get-Credential)

# Список из файла (по одному имени в строке)
.\Get-DomainDiskInventory.ps1 -ListPath .\computers.txt
```

Если запуск скриптов запрещен политикой выполнения:

```powershell
powershell -ExecutionPolicy Bypass -File .\Get-DomainDiskInventory.ps1
```

## Параметры

| Параметр           | Описание                                                         | По умолчанию        |
|--------------------|------------------------------------------------------------------|---------------------|
| `-ComputerName`    | Явный список компьютеров                                         | из AD               |
| `-ListPath`        | Текстовый файл со списком компьютеров                            | —                   |
| `-SearchBase`      | OU в AD, из которой выбираются компьютеры                        | весь домен          |
| `-OperatingSystem` | Маска ОС для фильтра в AD (`*Windows 10*`, `*Server*`)           | `*`                 |
| `-IncludeDisabled` | Опрашивать и отключенные учетные записи компьютеров              | выкл.               |
| `-ExcludeUsb`      | Не включать диски с интерфейсом USB                              | выкл.               |
| `-Credential`      | Учетные данные администратора                                    | текущий пользователь|
| `-OutputDir`       | Папка для отчетов                                                | `.\Reports`         |
| `-ThrottleLimit`   | Сколько компьютеров опрашивать одновременно (1–256)              | 32                  |
| `-TimeoutSec`      | Таймаут CIM-операций на один компьютер, сек (5–600)              | 30                  |

## Результат

Файлы создаются в папке `-OutputDir` (по умолчанию `Reports` рядом со скриптом):

- `DiskInventory_<дата>.csv` — все диски, разделитель `;`, UTF-8 с BOM (открывается в Excel).
- `DiskInventory_<дата>.html` — сводка и таблица дисков.
- `DiskInventory_<дата>_errors.csv` — компьютеры, которые не удалось опросить, и причина
  (создается только при наличии ошибок).

### Поля отчета

| Поле              | Описание                                                        |
|-------------------|-----------------------------------------------------------------|
| `ComputerName`    | Имя компьютера                                                  |
| `OperatingSystem` | Операционная система                                            |
| `ComputerModel`   | Производитель и модель компьютера                               |
| `DiskNumber`      | Номер диска в системе                                           |
| `Model`           | Модель диска                                                    |
| `SerialNumber`    | Серийный номер диска                                            |
| `UniqueId`        | Электронный идентификатор (WWN/NAA/EUI/SCSI), если доступен     |
| `PNPDeviceID`     | Идентификатор устройства Plug and Play                          |
| `MediaType`       | Тип носителя: HDD / SSD / SCM (если определен)                  |
| `InterfaceType`   | Интерфейс: SCSI, IDE, USB и т. д.                               |
| `SizeGB`          | Размер, ГБ                                                      |
| `Firmware`        | Версия прошивки                                                 |
| `Health`          | Состояние диска                                                 |
| `Partitions`      | Количество разделов                                             |
| `CollectedAt`     | Время опроса                                                    |

## Как определяется серийный номер

Берется первое непустое значение из источников: `MSFT_PhysicalDisk`, `Win32_DiskDrive`,
`Win32_PhysicalMedia`. Если драйвер отдает серийный номер HEX-строкой, она декодируется.

## Ограничения

- На Windows 7 / Server 2008 R2 нет класса `MSFT_PhysicalDisk`: `UniqueId` и `MediaType`
  будут пустыми.
- Для дисков за аппаратным RAID-контроллером система видит логический том, а не физические
  диски, поэтому серийные номера физических дисков не определяются.
- В отчетах содержатся серийные номера оборудования — не публикуйте их в открытом доступе.
